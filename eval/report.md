**Finding: the gate does not help on this corpus.** Raising the threshold only ever converts already-correct answers into wrongly-refused ones — answerable and unanswerable questions produce overlapping top-1 cross-encoder scores (e.g. a genuinely answerable question scored 0.448 while several correctly-abstained unanswerable questions scored 1.1–3.1). It takes a threshold of ~3.0 to suppress the single hallucination in this run, but that same threshold wrongly refuses 11 previously-correct answers to do it — a bad trade. The one hallucination we observed (a deliberately vague query matching a repeated boilerplate clause) retrieved with a *high* confidence score precisely because the retrieval was a strong lexical/semantic match — a similarity-threshold gate structurally cannot catch that failure mode. Recommendation: leave `CONFIDENCE_THRESHOLD = None` (disabled) until a richer signal than top-1 score (e.g. score *spread* across candidates, or a query-type classifier) is available to gate on.
